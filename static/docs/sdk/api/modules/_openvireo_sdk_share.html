    Module @openvireo/sdk/share

    Share links (SPEC §22): opening one without an account, and turning an item into share fields. Runs on the shared Rust core's lite module (primitives, share links and TOTP, about 190 KB gzip), so a public share page loads nothing else: no full core, no OPAQUE, KDBX or sync code.
