    Module @openvireo/sdk/opaque

    OPAQUE (SPEC §8, RFC 9807) over opaque-ke, compiled to WASM from opaque-wasm/ (see vendor/opaque/SOURCE.md). The module (~160 KB as base64) is loaded lazily on first use, through the package's own "./vendor/opaque-wasm.js" export so the path works from src/, dist/, bundlers and Bun.
