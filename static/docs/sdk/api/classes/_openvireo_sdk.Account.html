    importVault

    • importVault(
          source: Kdbx,
          opts?: { name?: string; orgId?: string },
      ): Promise<AccountVault>

      "Move to account": copies an open database (local, or synced with a self-hosted server), re-keys the copy to a fresh vault key, creates the vault (personal, or in an org this account manages, sealed to every confirmed owner and admin) and uploads it with If-None-Match: *. The original is never changed. As in Qt, the copy's root group takes the vault name (default: the root group's name) and its sync server remotes are dropped. If the vault was created but the upload failed, a VaultUploadError carries the vault, whose sync() uploads it later.

      Parameters

    recover

    • recover(

      ): Promise<{ secretKey: string; userId: string }>

      Resets the account with an approved ov_rc_ token (SPEC.md §18): a new Secret Key, KDF salt and keyset exactly as register makes them, a new OPAQUE record under the account email, and the old keys and vaults archived for 30 days on the server.     restoreFromArchive

    • restoreFromArchive(
          p: { oldPassword: string; oldSecretKey: string },
      ): Promise<{ restored: number }>

      Restores the vaults archived by a reset into the current keys (SPEC.md §18), with the old master password and the old Secret Key (the old Emergency Kit). Needs the account unlocked. OPAQUE login against the archived record (idU = the archived email the server returns), then the old keyset is unwrapped locally, each archived vault key re-sealed to the current enc_pk, and the proof signed with the old signing key. The old keys are wiped afterwards and the vault list reloaded.

      Errors: 401 unauthorized for a wrong old password; invalid_secret_key (local, before anything is restored) when the old Secret Key doesn't open the archived keyset; restore_locked (403); invalid_proof (400); session_expired (410); not_found (404) when there is no archive; forbidden (403) when the server wants a fresh sign-in.

      Parameters

      • p: { oldPassword: string; oldSecretKey: string }

      Returns Promise<{ restored: number }>
