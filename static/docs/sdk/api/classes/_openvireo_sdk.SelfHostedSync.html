    syncDatabase

    • syncDatabase(
          databaseId: string,
          kdbx: Uint8Array,
          credentials: KdbxCredentials,
          options?: SelfHostedSyncOptions,
      ): Promise<{ kdbx: Uint8Array; report: SyncReport }>

      Syncs a local database (its bytes and credentials: a password, passwordHashCredentials(hash) and/or a key file) with databases/<databaseId>; returns the merged bytes.

      • localChanged: false: nothing changed here since the last sync, so a cheap HEAD check runs first and, when the server is unchanged too, kdbx comes back as it is (outcome "unchanged"). Default true.
      • acceptServerState: true: start over from what the server has, after the user confirmed a server_rolled_back or server_lost_database.

      Parameters

      • databaseId: string
      • kdbx: Uint8Array
      • credentials: KdbxCredentials
