OpenVireo is a free, open-source, cross-platform password manager. It stores your passwords in the standard KeePass (KDBX) format on your own devices, fills them into apps and websites, and, if you want, syncs and shares encrypted vaults through an optional account, OpenVireo Web, or your own sync server.

The project

OpenVireo is developed in the open on GitHub by its maintainers and contributors. Beyond the desktop app and the OpenVireo Browser extension, it adds accounts with end-to-end encrypted sync and sharing, organizations, service accounts, a self-hosted sync server, and OpenVireo Web.

  • Maintainer: Bongani Mbigi (@bongani-m)
  • Contributors: everyone who has contributed to OpenVireo
  • Desktop app: github.com/openvireo/openvireo
  • Browser extension: github.com/openvireo/openvireo-browser
  • Sync server: github.com/openvireo/openvireo-sync-server

Want to help? Read the contributing guide.

OpenVireo is based on KeePassXC. It is an independent project, not affiliated with or endorsed by the KeePassXC Team, so please report OpenVireo problems to us. The original copyright and licence notices are kept in the source code, as the GPL requires.

Your .kdbx databases stay compatible: they open in KeePassXC, KeePassDX, Strongbox, and other KeePass clients.

Contact

Please report bugs and request features in the OpenVireo issue tracker on GitHub. Problems with the browser extension go to the OpenVireo Browser issue tracker.

If you need to report a security issue, please open a GitHub security advisory (preferred) or email security@openvireo.com. Please do not send user questions, bug reports, or support requests that way; the public issue tracker is the place for those.
