The short version

Pick Vaultwarden if several people need to share vaults on your own server, or you need Bitwarden's apps for Android, Safari and every browser.

Pick the OpenVireo Sync Server if you want a server that only ever stores encrypted files, and a complete KeePass file on every device that any KeePass app can open, with or without the server.

Where OpenVireo is different

The server only stores encrypted files

Each database is one encrypted KeePass file. The server checks the file signature and nothing else: it never parses your entries or merges anything. Each device downloads the file, merges and uploads it.

Your files work without it

Every device keeps a full KDBX file, which OpenVireo, KeePassXC or any other KeePass app can open. If you ever stop running the server, you still have your passwords in a standard format.

The same project as the apps

The sync server is built alongside the OpenVireo apps, so it doesn't have to keep up with someone else's API. Vaultwarden reimplements Bitwarden's server and isn't associated with Bitwarden.

Signed releases

Release binaries are signed and notarized for macOS, signed for Windows, and GPG-signed. There's a Docker image too, and storage in SQLite, Postgres or S3.

A hosted option when you want one

If you'd rather not run a server, the same apps sign in to a hosted OpenVireo account with sharing and organizations. Moving a database there takes a few clicks.

Where Vaultwarden is ahead

  • Sharing on your own server. Vaultwarden supports organizations, collections and groups, so a family or team can share on one server. A self-hosted OpenVireo server only syncs each user's own devices.
  • Every Bitwarden app. Android, Safari and every browser, plus the bundled web vault. OpenVireo has no Android app or Safari extension, and OpenVireo Web is a hosted app that can pair with your server but isn't self-hostable.
  • More features in the server. Emergency access, Send, and two-step sign-in with FIDO2, YubiKey and Duo.
  • A big community. Vaultwarden is widely used, with plenty of guides for every kind of setup.

How the security compares

Neither server has had a published third-party audit yet; an independent audit of OpenVireo is planned. Both rely on end-to-end encryption: the server stores data it can't decrypt.

With Vaultwarden, the Bitwarden apps encrypt each item and the server stores them in its database. With the OpenVireo Sync Server, the server stores each database as a single encrypted KeePass file and never looks inside it. Each device signs in with its own access token, which you can revoke if a device is lost; see Users and devices.

Switching from Vaultwarden

  1. In any Bitwarden app connected to your Vaultwarden server, export your vault in the .json format (not the encrypted one).
  2. Install OpenVireo, choose Database › Import… and pick Bitwarden. See Importing from Bitwarden. Then securely delete the export file.
  3. Install the OpenVireo Sync Server, add a user and a device, and set up Remote Sync in the database settings with the device's token.
