The short version

Stay with KeePassXC if you only want local files, prefer a project with a long track record and an independent audit, or want the version packaged in your Linux distribution.

Pick OpenVireo if you want the same files and features, plus built-in sync, sharing, an iPhone app and a web app, without putting together a cloud folder and third-party mobile apps yourself.

What stays the same

Your files

OpenVireo reads and writes the same KeePass (KDBX) files. Your existing databases open as they are, key files and YubiKeys included.

The desktop features

Auto-type, browser integration, passkeys, the SSH agent, Secret Service on Linux, KeeShare, database reports and the command-line tool all carry over.

No account needed

Like KeePassXC, OpenVireo works fully offline with local files and is free and open source under the GPL.

What OpenVireo adds

Built-in sync

Sync through a free OpenVireo account or your own sync server. Devices merge changes, so two edits never overwrite each other. KeePassXC leaves sync to a cloud folder.

Sharing and organizations

Share vaults with family or a team, with roles and an audit log, or send one item with a share link.

iPhone and web

The OpenVireo iPhone app, with AutoFill and passkeys, and OpenVireo Web in any browser.

Secrets for automation

Service accounts, the ov CLI, a GitHub Action and an SDK give CI jobs and servers their own access to a vault.

Where KeePassXC is ahead

  • Track record. KeePassXC has years of releases and a large community behind it. OpenVireo is new.
  • Audit and certification. KeePassXC had an independent audit in 2023, and version 2.7.9 received ANSSI's CSPN security certification. OpenVireo has neither.
  • Simplicity. KeePassXC has no account features at all, so there's less code and nothing that talks to a server unless you ask it to.
  • Packaging. KeePassXC is in nearly every Linux distribution's repositories.

How the security compares

For local databases, the encryption is the same: both apps use the KeePass format and its key derivation. OpenVireo's accounts add their own layer. Your account keys come from your password and a 128-bit Secret Key made on your device, sign-in uses OPAQUE, and the server only ever stores encrypted vaults.

Switching from KeePassXC

  1. Install OpenVireo and open your .kdbx file. There's nothing to import.
  2. Install the OpenVireo Browser extension and connect it, as you did with KeePassXC-Browser.
  3. Optionally, move the database to a free account to use it on your iPhone and in the browser.
