The release signing key below is published, but OpenVireo has not made a release with it yet. Until the first release is out, any file claiming to be a signed OpenVireo release is not from us.

By verifying the signatures of OpenVireo releases, you can prove the authenticity and integrity of the downloaded file: it was created by the OpenVireo project and its contents haven't been tampered with on the way.

A more detailed explanation is available in the Qubes-OS project documentation.

Note: OpenVireo releases are signed with OpenVireo's own key, not with the KeePassXC release key. A KeePassXC signature on a file means it is a KeePassXC release, not an OpenVireo one.

Download Options

OpenVireo releases are published on GitHub Releases in these package formats:

  • a *.dmg drag-and-drop installer for macOS
  • an *.msi installer and a *.zip archive with binaries for Windows
  • a self-contained executable *.AppImage for GNU/Linux
  • a *.tar.xz source tarball

Each release also contains SHA256SUMS.txt, the SHA-256 hashes of all its files, and SHA256SUMS.txt.asc, a PGP signature of that list made with the OpenVireo release key.

Verifying Releases – Windows and macOS

Windows installers and programs are code signed, and macOS apps are signed and notarized by Apple; the operating system checks them when you run them. You can also verify any package, on any platform, with the PGP signature as described below.

Verifying Releases via PGP – Linux, macOS, and Windows

Download SHA256SUMS.txt and SHA256SUMS.txt.asc from the release into the same folder as the package.

Step 1: Import the public key

On Windows and macOS you will need to install the gpg program. On Windows, we recommend Gpg4win. On macOS we recommend GPG Tools or gnupg installed via Homebrew.

{{< highlight bash >}}$ curl -sSL https://openvireo.com/openvireo-release.asc | gpg --import # or $ gpg --keyserver hkps://keys.openpgp.org --recv-keys 23F6403E9392E946475E7FD3B55683A43E98C11C{{< / highlight >}}

Step 2: Verify the PGP signature

Verify the authenticity of the checksum list, then check the package against it:

{{< highlight bash >}}$ gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt $ shasum -a 256 -c SHA256SUMS.txt --ignore-missing OpenVireo-*: OK{{< / highlight >}}

You want to see a "Good signature" line, and the primary key fingerprint in the output must match the fingerprint above. Then every package you downloaded must be listed as OK. If the verification fails or the fingerprint does not match, do NOT install the package. First, try downloading it again. If the checks are still failing, let us know by opening an issue.

gpg may warn that the key is "not certified with a trusted signature" if you have not marked the key as trusted. It can be ignored if (and only if) the fingerprint is correct.

Basic Integrity Check

Without gpg, you can still check a download against SHA256SUMS.txt. This will ONLY tell you that the file has been downloaded correctly without errors. It will NOT tell you if you can TRUST the download!

Linux and macOS

Open a terminal window and change directory to the folder you downloaded the files to, e.g. cd ~/Downloads, then run:

{{< highlight bash >}}$ shasum -a 256 -c SHA256SUMS.txt --ignore-missing OpenVireo-*: OK{{< /highlight >}}

Windows

Open a PowerShell window, change directory to the folder you downloaded the files to, e.g. cd C:\Users\username\Downloads, and run (replace the file name with the one you downloaded):

{{< highlight powershell >}}$f = "OpenVireo-2.8.0-x64.msi" (Get-FileHash $f).Hash -eq ((Select-String -SimpleMatch $f SHA256SUMS.txt).Line -split " ")[0].ToUpper(){{< / highlight >}}

You should see True appear. If not, then the download is invalid or your files are not together.
