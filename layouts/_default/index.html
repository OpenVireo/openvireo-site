About

The Project

KeePassXC is a modern, secure, and open-source password manager that stores and manages your most sensitive information.

You can run KeePassXC on Windows, macOS, and Linux systems. KeePassXC is for people with extremely high demands of secure personal data management. It saves many types of information, such as usernames, passwords, URLs, attachments, and notes in an offline, encrypted file that can be stored in any location, including private and public cloud solutions.

Security

Certified Security

KeePassXC 2.7.9 has been awarded a security Visa by the French National Cybersecurity Agency (ANSSI).

The security Visa has been awarded for passing ANSSI's First-level Security Certification (CSPN). The certificate demonstrates that KeePassXC has been tested for complying with security standards set by ANSSI, and it is recognised in France and in Germany.

More information can be found on our security audits and certifications page.
